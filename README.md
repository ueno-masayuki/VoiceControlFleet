# VoiceControlFleet

音声で指揮する、Webベースのリアルタイム艦隊戦略ゲーム

## 概要

VoiceControlFleetは、自然言語の音声コマンドで旧日本海軍の艦隊を指揮できる、革新的なWebベースRTSゲームです。LLM（大規模言語モデル）が音声コマンドを解釈し、さらにゲームマスターとして動的に敵艦隊を管理します。

## 特徴

- 🎤 **自然言語での艦隊指揮**: 定型コマンド不要、話すように指示を出せる
- ⚓ **旧日本海軍の艦名**: 大和、武蔵、赤城、加賀など歴史的な艦名を使用
- 🤖 **LLMゲームマスター**: AIが戦況を判断し、最適な敵艦隊を出現させる
- 🌐 **Webブラウザで動作**: インストール不要、ブラウザだけでプレイ可能
- ⚡ **リアルタイム戦略**: アクション重視のRTSゲーム

## ゲーム仕様

- **プレイモード**: シングルプレイヤー vs AI
- **艦隊規模**: 約10隻（戦艦、空母、巡洋艦、駆逐艦等）
- **音声コマンド例**:
  - 「全艦、北東に移動」
  - 「第一艦隊は敵艦を攻撃、第二艦隊は防衛」
  - 「損傷した艦は後退して修理」
  - 「戦艦大和、敵主力艦を砲撃」

## 技術スタック

- **フロントエンド**: Web（HTML5 Canvas/WebGL検討中）
- **音声認識**: Web Speech API / Whisper
- **自然言語処理**: LLM（GPT/Claude等）
- **言語**: JavaScript/TypeScript

## セットアップ

### 必要要件
- Node.js 18以上
- npm または yarn

### インストール

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# ビルド
npm run build

# プレビュー
npm run preview
```

### 開発サーバー

開発サーバーは `http://localhost:3000` で起動します。

### LLM API設定（オプション）

LLMによる高度な音声コマンド解釈を使用する場合：

1. `.env`ファイルを作成
   ```bash
   cp .env.example .env
   ```

2. APIキーを設定
   ```
   VITE_ANTHROPIC_API_KEY=your_api_key_here
   ```

APIキーがない場合でも、デモモード（パターンマッチング）で動作します。
